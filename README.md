# Party Palace – Pictionary, Uno & Ludo
Open link → landing page → friends join with a 4-letter room code. No sign-in needed.

## Deploy free on Render (gives you a public link)
1. Put this folder in a new GitHub repo.
2. On render.com: New → Web Service → connect the repo.
3. Build command: `npm install`   Start command: `npm start`   Plan: Free.
4. Share the `https://….onrender.com` link. (Free plan sleeps when idle; first open can take ~50 s.)

## Run locally
`npm install && npm start` → http://localhost:3000
